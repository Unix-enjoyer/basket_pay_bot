# Полный список реплик бота

Справочник всех текстов, которые бот отправляет пользователям и администраторам.
Формулировки можно редактировать в одном списке, не обращаясь к файлам кода.
Значения в фигурных скобках подставляются автоматически.

## Регистрация (обычный пользователь)

| Реплика бота | Когда отвечает |
|---|---|
| «Привет! Здесь можно зарегистрироваться на Баскет Фест. Билет оформляется только на тебя. Чтобы начать, нажми кнопку «🎟 Зарегистрироваться».» | `/start` — приветствие |
| «Переведи {цена} ₽ по следующим реквизитам: {реквизиты}. Затем пришли чек файлом в формате PDF. Фото или скриншот не подойдут.» | нажата кнопка «Зарегистрироваться», названа цена |
| «Чтобы начать регистрацию, сначала нажми кнопку «🎟 Зарегистрироваться».» | прислали файл, но регистрация ещё не начата |
| «Ожидаю чек об оплате на сумму {цена} ₽. Пришли его файлом в формате PDF.» | повторно нажали кнопку регистрации, уже ожидая чек |
| «Чек принят. У тебя не указан username в Telegram, поэтому для оформления билета нужен номер телефона. Пришли его в формате +7 123 456 78 90.» | чек принят, но у пользователя нет username |
| «Для завершения оформления билета пришли номер телефона в формате +7 123 456 78 90.» | повторно нажали кнопку регистрации, уже ожидая телефон |
| «Не удалось распознать номер телефона. Пришли его в формате +7 123 456 78 90.» | телефон прислан не в том формате |
| «Твой билет на Баскет Фест оформлен! Назови этот код на входе: {код}. Данные билета: {тег/телефон}. Ждём тебя на нашем Баскет Фесте 26 декабря! 🏀» | билет полностью оформлен |
| «Оплата принята, но не удалось выдать код входа. Свяжись с организаторами (список из .env) — они выдадут код вручную.» | технический сбой уже после записи оплаты в базу |
| «Пришли чек об оплате файлом в формате PDF.» | написали текст, когда бот ждёт именно файл |

## Ошибки при разборе чека

| Реплика бота | Когда отвечает |
|---|---|
| «Регистрация через бота доступна только участникам нашей группы.» | нажали «Зарегистрироваться», но не состоят в группе |
| «Пришли чек файлом в формате PDF. Скриншот или фото не подойдут.» | прислан не PDF-файл |
| «Не удалось обработать чек. Свяжись с организаторами (список из .env), чтобы проверить оплату.» | PDF повреждён или не распознался |
| «В чеке перевод не отмечен как успешный. Проверь статус оплаты.» | статус в чеке не «Успешно» |
| «Номер счёта получателя в чеке не совпадает с указанным для оплаты билета. Проверь реквизиты перевода.» | не совпал `RECEIVER_CONTRACT` |
| «Этот чек уже был обработан. Повторно использовать его для оформления билета нельзя.» | такая квитанция уже есть в базе (дубль) |
| «Сумма в чеке меньше стоимости билета. Свяжись с организаторами (список из .env), чтобы уточнить дальнейшие действия.» | сумма в чеке меньше ожидаемой |

## Администратор — добавление гостя вручную

| Реплика бота | Когда отвечает |
|---|---|
| «Пришли username гостя в Telegram (например, @tag) или его номер телефона.» | нажата кнопка «Добавить гостя» |

## Администратор — назначение и снятие администраторов

| Реплика бота | Когда отвечает |
|---|---|
| «Чтобы назначить администратора, перешли сюда любое сообщение этого пользователя. Затем ответь на пересланное сообщение командой /add_admin.» | нажата кнопка «Добавить админа» либо отправлена `/add_admin` без ответа на сообщение |
| «Чтобы снять права администратора, перешли сюда любое сообщение этого пользователя. Затем ответь на пересланное сообщение командой /remove_admin.» | аналогично для снятия |
| «Не удалось определить пользователя: его настройки приватности скрывают автора пересланных сообщений. Попроси его разрешить отображение автора при пересылке и попробуй снова.» | у пересланного сообщения скрыт автор (при добавлении) |
| «Не удалось определить пользователя: его настройки приватности скрывают автора пересланных сообщений.» | то же самое при снятии |
| «Не удалось определить пользователя по пересланному сообщению. Перешли сообщение, отправленное от личного аккаунта.» | переслано не от конкретного человека (канал/группа) |
| «Пользователь @{тег} назначен администратором.» | администратор успешно добавлен |
| «У пользователя @{тег} сняты права администратора.» | администратор успешно снят |
| «Снять права главного администратора нельзя.» | попытка снять супер-админа |

## Администратор — вход на Баскет Фест

| Реплика бота | Когда отвечает |
|---|---|
| «Чтобы отметить вход гостя на Баскет Фест, пришли его код. Код можно отправить в любой момент — включать отдельный режим не нужно.» | нажата кнопка «Вход» (справочно) |
| «Гость {тег} найден. Вход отмечен. Добро пожаловать на Баскет Фест!» | код найден, гость входит впервые |

| «Нет отмеченных тобой входов, которые можно отменить.» | нажата «Отменить последний вход», но отмечать нечего |
| «Отметка о входе отменена: {код} — {тег}. Гость больше не отмечен как вошедший.» | последний вход этого администратора отменён |

## Назначение админа по ID (запасной способ)

| Реплика | Когда |
|---|---|
| «Твой ID: {число}» | любой пользователь написал /myid |

## Приписка при нескольких организаторах

В трёх репликах про «Свяжись с организаторами…» (если в ORGANIZERS указано несколько человек через запятую) в конце добавляется:
«Пожалуйста, не пиши всем организаторам сразу, а только одному. Они постараются ответить как можно быстрее.»
